# レシートのテストデータ

実レシートは使わない。写っていた店舗、金額、購入内容を書き写すのも禁止する。店名は架空にする。

## 必ず含めるパターン

| パターン | 例 | 期待する結果 |
| --- | --- | --- |
| 半角カナの略称 | `ｼｮｯｷｾﾝｻﾞｲ    198` | 商品名、金額 198 |
| 容量つき | `ﾄｲﾚｯﾄﾍﾟｰﾊﾟｰ 12R   458` | 名寄せで容量を除去 |
| 数量が同じ行 | `ｷﾞｭｳﾆｭｳ 1L 2ｺ X238   476` | 数量 2、金額 476 |
| 数量が次の行 | `ｷﾞｭｳﾆｭｳ 1L` と `  2ｺ X 238   476` | 1 商品にまとめる |
| 軽減税率の印 | `ﾄﾘﾑﾈﾆｸ    412 ※` | 印を商品名に含めない |
| 値引き | `ｼｬﾝﾌﾟｰ 598` と `  値引  -100` | 商品を増やさない |

## 商品にしない行
合計、小計、消費税、内税、外税、お預かり、お釣り、釣銭、現金、クレジット、ポイント、電話番号、登録番号、レジ番号、担当者

## 認識の誤りも含める
OCR で起こりやすい誤りを、正解とは別のケースで用意する。

- 似た文字の混同: `ー` と `一`、`0` と `O`、`1` と `l`、`ﾊﾟ` と `ﾊ`
- 行の分断、金額のずれ、空白の欠落
- 日付の形式違い: `2026年10月31日`、`2026/10/31`、`26-10-31`、和暦の `令和8年10月31日`
- 読み取れない行が混ざる場合: 落とさず、確認画面で直せる形で返す

## 書き方
- 入力は OCR の結果を模した行のリストとし、位置情報が必要なテストには行の座標も持たせる
- 期待値には店名、日付、合計金額、商品(名前、数量、金額)を明記する
- 商品の金額の合計と合計金額を揃える。値引きや外税の例では計算の内訳をコメントに書く
- 期待値は実装の出力を貼り付けず、入力から手で決める
